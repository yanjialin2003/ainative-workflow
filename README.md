# Neon Stack

一个零依赖的俄罗斯方块小游戏，兼顾桌面键盘操作和移动端触控体验。

## 运行方式

直接打开 `index.html` 即可运行。

如果需要本地静态服务，可在仓库根目录执行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 操作方式

- `Enter`：开始 / 重开
- `←` / `→`：左右移动
- `↑` / `X`：顺时针旋转
- `Z`：逆时针旋转
- `↓`：加速下落
- `空格`：直接落到底
- `P`：暂停 / 继续

移动端可使用页面内的触控按钮操作。

## 计分规则

- 软降：`+1 / 格`
- 硬降：`+2 / 格`
- 单消 / 双消 / 三消 / 四消：`100 / 300 / 500 / 800 × 当前等级`
