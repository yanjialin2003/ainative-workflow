博客详情页不是把 Markdown 渲染出来就结束了，真正影响可读性的通常是异常内容宽度。

## 需要优先处理的元素

### 1. 代码块

长代码必须允许横向滚动，不能把整页版心撑破。

```bash
npm install
npm run build
```

### 2. 图片

正文图片要跟随容器缩放，并保留合理的圆角和留白。

### 3. 外链

外链应该有清晰的视觉样式，例如下划线或图标提示，让读者知道它会跳出当前页面。

## 结论

详情页是内容站点的核心体验面，优先级应该高于首页装饰效果。
